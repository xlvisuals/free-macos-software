# Awesome macOS 

A curated collection of awesome software, utilities, and power-user tools to supercharge your macOS experience. 

[![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

---

## Repository Contents

This repository is divided into two primary, highly detailed guides depending on what you are looking for:

### 1. [Essential macOS Power User Toolkit](Essential%20macOS%20power%20user%20toolkit.md)
The ultimate minimalist toolkit for advanced users looking for efficient workflows across a variety of tasks (System Utilities, Productivity, File Management, Graphics, Security, Virtualisation).

### 2. [Curated List of Free Software for macOS](Curated%20list%20of%20free%20software%20for%20macOS.md)
A comprehensive directory of top-tier, completely free applications across multiple categories (Productivity, Development, Media, System Utilities, and more). No hidden subscriptions, no paywalls—just great software.

## Contributing

Contributions are welcome! If you have a favorite app or power-user tool that isn't listed yet:

1. Fork this repository.
2. Update the relevant file (`Curated list of free software for macOS.md` or `Essential macOS power user toolkit.md`).
3. Submit a Pull Request.

*Please ensure any suggested software is stable, actively maintained, and safe to use.*
