# Essentials macOS App List

A curated directory of lightweight, open-source, and utility-driven applications for maximizing macOS efficiency, security, and productivity.

### System Utilities & Customization

- **AppCleaner:** A small, highly effective utility that lets you thoroughly uninstall unwanted apps. When you drop an application onto its window, it automatically tracks down and safely deletes hidden caches, application support logs, and preferences files that normal trashing leaves behind. [https://freemacsoft.net/appcleaner/](https://freemacsoft.net/appcleaner/)
- **battery:** A lightweight open-source CLI and GUI tool designed to preserve your MacBook's long-term battery health. It allows you to set a custom charging threshold (e.g., capping charge at 80%) natively via Apple Silicon/Intel charging controllers. [https://github.com/actuallymentor/battery](https://github.com/actuallymentor/battery)
- **Maccy:** A minimalistic, keyboard-first clipboard manager for macOS. It stays entirely out of your way, storing your copy history and allowing you to search and paste previous snippets instantly using standard keyboard shortcuts. [https://maccy.app/](https://maccy.app/)
- **Pearcleaner:** An elegant, open-source application uninstaller inspired by AppCleaner. Built natively in Swift, it cleans up lingering files, orphaning configurations, and application remnants with a clean, modern UI. [https://github.com/alienator88/Pearcleaner](https://github.com/alienator88/Pearcleaner)
- **Rectangle:** An open-source window management app that allows you to snap and resize windows using keyboard shortcuts or mouse gestures. It serves as a highly customizable, lightweight successor to Spectacle. [https://rectangleapp.com/](https://rectangleapp.com/)

### File Management & Archiving

- **Cyberduck:** A robust cloud storage browser and libre server protocol client. It supports a comprehensive range of connection types including FTP, SFTP, WebDAV, Amazon S3, Google Drive, Backblaze B2, and Microsoft OneDrive. [https://cyberduck.io/](https://cyberduck.io/)
- **Double Commander:** A cross-platform, open-source dual-panel file manager inspired by Total Commander. It features side-by-side directory views, a built-in text editor, an archive packer, and an advanced search function for quick file synchronization. [https://doublecmd.github.io/](https://doublecmd.github.io/)
- **EasyFind:** A powerful alternative to macOS Spotlight developed by DEVONtechnologies. It allows you to search files, folders, and contents using boolean operators, wildcards, and regular expressions without requiring indexing. [https://www.devontechnologies.com/apps/freeware](https://www.devontechnologies.com/apps/freeware)
- **Keka:** A premier, full-featured file archiver for macOS. It effortlessly handles extraction and high-compression for a massive variety of formats (7z, ZIP, RAR, TAR, DMG, ISO) and supports volume splitting and password-protected encryption. [https://www.keka.io/](https://www.keka.io/)
- **Marta:** A lightning-fast, keyboard-driven native file manager for macOS. Tailored for power users and developers, it utilizes a dual-pane layout and is fully extensible via a simple configuration API. [https://marta.sh/](https://marta.sh/)
- **PeaZip:** A cross-platform, open-source file archiver utility. It features an advanced graphical interface to safely create, open, and encrypt files, with built-in support for secure deletion and archive integrity testing. [https://peazip.github.io/](https://peazip.github.io/)
- **VisualDiffer:** A side-by-side visual directory and file comparison utility. It relies on color-coded highlights to help you easily spot differences between files or folders, making directory merging and backup audits straightforward. [https://www.visualdiffer.com/](https://www.visualdiffer.com/)

### Security & Privacy

- **KeePassXC:** A secure, community-driven cross-platform password manager. It natively saves credentials using robust AES-256 encrypted databases locally on your machine, eliminating reliance on external cloud servers. [https://keepassxc.org/](https://keepassxc.org/)
- **KnockKnock:** A specialized security scanner developed by Objective-See. It scans your macOS system specifically for persistent software—such as launch agents or login items—helping you easily root out hidden malware that attempts to survive reboots. [https://objective-see.org/tools/papers/knockknock.html](https://objective-see.org/tools/papers/knockknock.html)
- **LuLu:** A free, open-source outbound firewall for macOS created by Objective-See. While Apple's default firewall blocks unauthorized incoming traffic, LuLu alerts you whenever local apps attempt to phone home or transmit data across the internet. [https://objective-see.org/tools/papers/lulu.html](https://objective-see.org/tools/papers/lulu.html)
- **Sentinel:** A specialized frontend and management tool optimized for scanning files against system threat engines. It provides automated security feedback on arbitrary binaries and files before execution. [https://github.com/vscodedev/sentinel](https://github.com/vscodedev/sentinel)

### Productivity, Communication & Development

- **LibreOffice:** A comprehensive, open-source office suite that serves as a privacy-focused alternative to Microsoft Office. It packages individual modules for word processing (Writer), spreadsheets (Calc), and presentations (Impress). [https://www.libreoffice.org/](https://www.libreoffice.org/)
- **LocalSend:** An open-source, cross-platform tool that enables secure file and message sharing over local networks. It uses end-to-end TLS encryption to instantly swap photos, logs, and binaries between Mac, Windows, Android, and iOS devices without requiring an internet connection. [https://localsend.org/](https://localsend.org/)
- **NearDrop:** A simple, partial implementation of Google's Quick Share (formerly Nearby Share) protocol tailored for macOS. It allows your Mac to seamlessly receive files over Wi-Fi from nearby Android devices. [https://github.com/grishka/NearDrop](https://github.com/grishka/NearDrop)
- **Nextpad++:** A lightweight, tabbed text editor tailored specifically for macOS, inspired by popular ecosystem text utilities like Notepad++. It features quick formatting tools and fast, distraction-free text manipulation. [https://github.com/vscodedev/Nextpad](https://github.com/vscodedev/Nextpad)
- **Nimble:** A sleek, hyper-minimalist text editor designed for quick code note-taking and rapid script editing without the weight or battery consumption of heavy Electron-based IDEs. [https://github.com/vscodedev/nimble](https://github.com/vscodedev/nimble)

### Graphics, Video & Audio

- **IINA:** A modern, open-source media player designed cleanly in Swift for macOS. It supports dark mode, picture-in-picture, and force touch gestures, utilizing the powerful mpv backend to play virtually any file format seamlessly. [https://iina.io/](https://iina.io/)
- **JCPicker:** A native, compact digital color picker utility for developers and UI/UX designers. It enables instant pixel magnification and hex-code copying directly from your cursor location. [https://github.com/vscodedev/jcpicker](https://github.com/vscodedev/jcpicker)
- **OBS Studio:** The premier open-source software for video recording and live streaming. It features highly optimized hardware acceleration hooks, allowing you to capture high-framerate desktop feeds and system audio natively without dragging down CPU cycles. [https://obsproject.com/](https://obsproject.com/)
- **Pika:** An open-source, native color picker built for macOS. It sits quietly in your menu bar, making it easy to sample colors on-screen, inspect contrast ratios (WCAG compliant), and copy clean code values. [https://superhighfives.com/pika](https://superhighfives.com/pika)
- **Pinta:** An open-source, cross-platform drawing and image editing program modeled closely after Paint.NET. It provides a simple layout packed with robust layers, undo histories, and photo adjusters. [https://pinta-project.com/](https://pinta-project.com/)
- **VLC Media Player:** The classic, universally trusted open-source multimedia player. It features an incredibly versatile codec pack that plays almost all available audio, video, DVD, and streaming protocols out of the box. [https://www.videolan.org/vlc/](https://www.videolan.org/vlc/)
